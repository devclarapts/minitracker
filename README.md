# Mini Expense Tracker

Programa simples de terminal para controlar despesas, feito em Python puro.
Nele voce registra gastos com descricao, valor e categoria e pode ver o total acumulado.
As despesas ficam salvas apenas enquanto o programa esta aberto.

## Funcionalidades

- Adicionar despesa com descricao, valor e categoria
- Listar todas as despesas cadastradas
- Mostrar o total de despesas
- Avisar quando nao houver nenhuma despesa cadastrada
- Encerrar o programa pelo menu

## Como executar

```bash
python main.py
```

Basta ter o Python 3 instalado. O programa nao usa nenhuma biblioteca externa.

## Tecnologias

- Python 3
